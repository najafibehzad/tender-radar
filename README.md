# 🎯 رادار مناقصات

وب‌اپ استخراج، جستجو و پایش **آگهی‌های مناقصه، مزایده، استعلام و فراخوان** از سایت‌های
**شهرداری‌ها، دهیاری‌ها و سامانه‌های تجمیع‌کنندهٔ** استان‌های **تهران و البرز**.

---

## اجرا

```bash
cd tender-radar
node server.mjs
```

سپس در مرورگر باز کنید: **http://127.0.0.1:3731**

یا در ویندوز روی `run.cmd` دوبار کلیک کنید (خودش مرورگر را باز می‌کند).

خط فرمان:

```bash
node cli.mjs scan                    # اسکن همهٔ منابع
node cli.mjs scan --only fardis      # اسکن یک منبع
node cli.mjs detect https://x.ir     # شناسایی نوع سامانهٔ یک سایت
node cli.mjs list                    # فهرست منابع
```

| **افزودن موضوع دلخواه** | با تعیین نام و کلیدواژه‌ها |

## روش‌های استخراج (آداپترها)

| آداپتر | کاربرد |
|---|---|
| `setadiran` | **سامانه تدارکات الکترونیکی دولت (ستاد ایران)** — مناقصه/مزایده/استعلام/خرید همهٔ دستگاه‌های دولتی. **دو مسیر مستقل:** API (`gw.setadiran.ir`) و مسیر پشتیبان HTML (`etend.setadiran.ir/etend/index.action`). ⚠️ دسترسی فقط از داخل ایران |
| `odata` | سامانه‌های OData — مثل **سامانه امور قراردادهای دهیاری‌های استان تهران** (`/OData/deals`) |
| `wordpress` | سایت‌های وردپرسی با REST API (`/wp-json/wp/v2/posts?search=`) — دقیق‌ترین روش |
| `rss` | فیدهای RSS/Atom |
| `html` | استخراج عمومی از HTML (شامل سایت‌های دورتال/ASP.NET) |
| `sitemap` | کشف نشانی‌ها از نقشهٔ سایت |

## منابع پیش‌فرض

**سامانه‌های مرکزی:** ستاد ایران (۱۳ شهر تهران و البرز) · سامانه امور قراردادهای دهیاری‌های استان تهران

**شهرداری‌ها — البرز:** فردیس · کرج · کرج امروز · اشتهارد · طالقان · هشتگرد · کمال‌شهر
**شهرداری‌ها — تهران:** شهریار · رباط کریم · قدس · بهارستان · ملارد · قرچک · پاکدشت · تهران ·
اسلامشهر · ورامین · چهاردانگه · فیروزکوه · دماوند · نسیم‌شهر · شاهدشهر · نصیرشهر · باغستان

> شهرداری‌های پردیس، پیشوا، ساوجبلاغ، نظرآباد، چهارباغ، محمدشهر، گرمدره، ماهدشت، گلستان، اندیشه،
> وحیدیه، صالحیه، صباشهر، رودهن و بومهن دامنهٔ تأییدشده‌ای پیدا نکردند. با «افزودن شهر / منبع جدید»
> و دکمهٔ «بررسی و شناسایی سایت» می‌توانید هر کدام را اضافه کنید.

> **نکته:** شهرهای کرج، قدس، ملارد، شهریار، رباط کریم، اسلامشهر، بهارستان، اشتهارد، ساوجبلاغ،
> چهارباغ، نظرآباد، تهران و فردیس **از طریق ستاد** پوشش داده می‌شوند؛ پس اگر سایت خودشان
> اسکرپ‌نشدنی باشد (محتوای جاوااسکریپتی)، پوشش از دست نمی‌رود.

## ابزارهای عیب‌یابی

```bash
node tools/smoke-test.mjs        # آزمون دودی همهٔ نقطه‌های پایانی API (۲۵ بررسی)
node cli.mjs setad-test          # تشخیص گام‌به‌گام اتصال به ستاد ایران
node cli.mjs detect <url>        # شناسایی نوع سامانهٔ یک سایت جدید
node tools/diag-wp.mjs fardis    # بررسی خروجی خام یک منبع وردپرسی و اثر فیلتر تاریخ
node tools/probe-paths.mjs <url> # جستجوی مسیر آگهی‌ها در یک سایت
node tools/mock-setad.mjs        # سرور ساختگی ستاد (آزمون آداپتر بدون IP ایران)
```

آزمون آداپتر ستاد بدون دسترسی به ایران:

```bash
node tools/mock-setad.mjs &
SETAD_GW=http://127.0.0.1:3799 SETAD_FE=http://127.0.0.1:3799/centralboard node cli.mjs scan --only setadiran
```

## نکات مهم دربارهٔ دسترسی و پیکربندی

**۱) محدودیت جغرافیایی.** دامنه‌های `setadiran.ir` و سایت‌های `karaj.ir`، `tehran.ir` و
`hashtgerd.ir` دسترسی از خارج ایران را می‌بندند. برنامه را روی کامپیوتر **داخل ایران** اجرا کنید.

**۲) گواهی‌های SSL منقضی.** چند سایت شهرداری گواهی منقضی یا ناقص دارند
(`eslamshahr.ir` و `evaramin.ir` گواهی منقضی، `malard.ir` زنجیرهٔ ناقص). مرورگر و ابزارهای
خط فرمان با `-k` رد می‌شوند ولی کتابخانهٔ شبکهٔ استاندارد رد می‌کند → پیام «خطای شبکه».
این منابع از داخل ایران با مرورگر باز می‌شوند.

**۳) خطاهای گذرا واقعی‌اند.** سایت‌های شهرداری کند و ناپایدارند؛ یک منبع ممکن است یک اسکن
خطا بدهد و اسکن بعدی موفق شود (نمونه: هشتگرد یک‌بار ۵۰۳ و بار بعد ۶ آگهی؛ ملارد/اسلامشهر/ورامین
۲۰۰ ولی زیر بار تایم‌اوت). برای همین **دکمهٔ «اسکن منابع خطادار»** گذاشته شده است.

**۴) اتصال به ستاد نوسانی است.** یک اسکن کامل ۲۵۰ آگهی کرج می‌آورد و نیم‌ساعت بعد ممکن است
بوت‌استرپ شکست بخورد. آداپتر ۴ بار تلاش می‌کند، اگر نشد مسیر HTML پشتیبان را می‌زند، و در
نهایت پیام روشن می‌دهد. با `node cli.mjs setad-test` علت دقیق را ببینید.

**۵) بازهٔ زمانی و سقف هر منبع.** این دو تنظیم مستقیم روی تعداد نتیجه اثر دارند:
- `lookbackDays` (پیش‌فرض ۱۵۰): با ۲۰ روز، فقط آگهی‌های سه هفتهٔ اخیر می‌آید.
- `maxItemsPerSource` (پیش‌فرض ۳۰۰): سقف سراسری. **منابع بزرگ می‌توانند سقف مستقل داشته باشند**
  (کلید `maxItems` در خود منبع — ستاد روی ۴۰۰ تنظیم است چون کرج تنها ۴۳۵ آگهی فعال دارد).
مقدارهای خارج از بازه در `/api/settings` کلمپ می‌شوند تا تنظیم نابخردانه نتیجه را خراب نکند.

**۶) `data/sources.json` را وقتی سرور در حال اجراست دستی ویرایش نکنید.** سرور با
`saveRegistry` روی همان فایل می‌نویسد و ممکن است تغییر شما را بازنویسی کند. اول سرور را ببندید،
یا از خود رابط کاربری/API استفاده کنید.

## ساختار پروژه

```
tender-radar/
├── server.mjs              سرور وب‌اپ و API
├── cli.mjs                 ابزار خط فرمان (scan · detect · setad-test · list)
├── run.cmd                 اجرای ویندوزی + باز کردن مرورگر
├── lib/
│   ├── fetcher.mjs         دریافت با مهلت، تلاش مجدد و موازی‌سازی
│   ├── text.mjs            نرمال‌سازی فارسی، تبدیل تاریخ شمسی، موضوعات

│   ├── scanner.mjs         هماهنگ‌کنندهٔ اسکن و یکپارچه‌سازی
│   ├── detect.mjs          تشخیص خودکار نوع سامانه
│   └── adapters/           setadiran · odata · wordpress · rss · html · sitemap
├── data/
│   ├── sources.json        رجیستری شهرها/منابع + موضوعات + تنظیمات
│   ├── cache.json          آخرین نتایج اسکن
│   ├── scan-log.json       تاریخچهٔ اسکن‌ها
│   └── setadiran-locs.json حافظهٔ کد استان/شهر ستاد
├── public/                 رابط کاربری (index.html · app.js · styles.css)
└── tools/
    ├── smoke-test.mjs      آزمون دودی همهٔ API (۲۵ بررسی)
    ├── mock-setad.mjs      سرور ساختگی ستاد برای آزمون بدون ایران
    ├── diag-wp.mjs         بررسی خروجی خام منابع وردپرسی
    ├── probe-paths.mjs     جستجوی مسیر آگهی‌ها در یک سایت
    ├── check-ui.mjs        بررسی رندر اجزای رابط از DOM
    └── probe.mjs           بررسی دسترسی و نوع سامانهٔ چند سایت
```

## API

| روش | مسیر | کار |
|---|---|---|
| GET | `/api/status` | رجیستری، آمار، وضعیت اسکن |
| POST | `/api/scan` | اجرای اسکن |
| GET | `/api/scan/status` | پیشرفت اسکن |
| GET | `/api/items` | آگهی‌ها با فیلتر (`q`, `topic`, `city`, `province`, `kind`, `source`, `days`, `hasDeadline`, `today`, `sort`) |
| POST | `/api/detect` | شناسایی نوع سامانهٔ یک نشانی |
| GET/POST | `/api/sources` | فهرست/افزودن منبع |
| PUT/DELETE | `/api/sources/:id` | ویرایش/حذف منبع |
| POST | `/api/sources/:id/toggle` | فعال/غیرفعال |
| GET/POST | `/api/topics` | فهرست/افزودن موضوع |
| POST | `/api/settings` | تنظیمات |
| GET | `/api/export.csv` / `.json` | برون‌بری |
